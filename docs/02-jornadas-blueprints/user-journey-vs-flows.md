# User Journey × User Flows

Enquanto a **User Journey** mapeia a experiência macro do usuário (fases, pensamentos, curva emocional e dores), o **User Flow** detalha a sequência lógica de telas, decisões do sistema e caminhos de recuperação de erro.

!!! note "Arquivo-molde da Sprint 03"
    Expanda e personalize livremente as seções e perguntas abaixo com base nas aulas e na bibliografia da sua Issue, mantendo o formato das *Smart Badges*, do bloco *Como auditar* e das *Referências*.

---

## Coerência entre Jornada Emocional e Fluxo de Telas

- [ ] **Cada ponto crítico de frustração ou ansiedade identificado na User Journey possui um caminho simplificado e assistido no User Flow** [[1]](#ref-1)
    - `👤 Persona: TDAH / Ansiedade` `👤 Persona: Usuário Iniciante` `⚖️ Norma/Base: Kalbach — Mapeamento de Experiências` `🛠️ Ferramenta: FigJam / Miro`
    ??? info "Como auditar / Passo a passo"
        1. Localize a etapa de maior atrito emocional na User Journey.
        2. Confira no User Flow correspondente se há instruções claras, validação amigável e opção simples de retorno.

- [ ] **Os User Flows preveem estados vazios, desvios de erro e navegação linear acessível por teclado sem becos sem saída** [[2]](#ref-2)
    - `👤 Persona: Motora / Teclado` `⚖️ Norma/Base: WCAG 2.2 — 3.2 Previsibilidade` `🛠️ Ferramenta: Figma`
    ??? info "Como auditar / Passo a passo"
        1. Percorra o fluxo completo simulando dados inválidos ou cancelamento no meio da tarefa para confirmar que o usuário nunca fica preso.
